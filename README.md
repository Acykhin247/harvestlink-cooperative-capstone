# HarvestLink Cooperative — Performance Analysis

A data-driven analysis of a Ghanaian farmer cooperative's profitability, 
post-harvest losses, and market channel performance — built in Excel and Power BI.

## The Question
How can HarvestLink improve farmer profitability, reduce post-harvest losses, 
and make smarter market decisions — using 500 real farm records across 
6 crops and 5 districts?

## Key Finding
Two crops drove 73% of total margin — but the real insight came from normalizing 
by acreage: a district that looked like the weakest performer was actually the 
2nd-most efficient per acre in the cooperative. It wasn't underperforming — 
it was under-planted.
